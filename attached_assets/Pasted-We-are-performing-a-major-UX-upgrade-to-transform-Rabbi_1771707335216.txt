PART 1 — Premium Long-Scroll Investigation Editor
====================================================

Replace the current tab-based CMS with a continuous long-scroll narrative editor.

GOAL:
Investigations are built as immersive vertical dossiers with checkpoint nodes.

LAYOUT:

Left Sidebar:
- Investigation list
- Sticky Node Navigator (auto-updates on scroll)
- Status badge (Draft / Review / Published)
- Progress %
- Jump-to-node links

Main Scroll Editor:
- Continuous vertical editing
- No tab switching
- All blocks inserted inline

Block Types:
1) Section Header Block
2) Narrative Paragraph Block (rich text)
3) Image / Media Block (drag/drop, caption, source)
4) Claim Block (confidence meter + linked sources)
5) Node Checkpoint Block (collapsible, auto-numbered)
6) Timeline Entry Block (date + event + sources)

FUNCTIONAL:
- Drag reorder blocks
- Drag reorder nodes
- Highlight text → Convert to Claim
- Nodes collapsible
- Sticky navigator syncs live
- Autosave
- Smooth insertion animations
