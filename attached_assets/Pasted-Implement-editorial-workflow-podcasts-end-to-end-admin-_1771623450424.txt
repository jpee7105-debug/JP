1) Add status to rabbit holes and podcast episodes: Draft / Review / Published
- Default new content = Draft
- Public Home/Discover/Search/Connections show ONLY Published

- Admin preview: logged-in employees can preview Draft/Review and see a small status badge (only in admin preview)

2) Editorial dashboard /admin/dashboard
- tabs: My Drafts, In Review, Needs Fixes, Published, Recently Edited
- filters: status, category, editor, updated date
- search by title/slug
- Editors can move Draft -> Review

3) Publish checklist (must block publishing)
Block publish unless:
- required fields exist (title, summary, slug, category)
- minimum depth nodes (default 5)
- every claim has >= 1 evidence source
- all referenced sourceIds/mediaIds/nodeIds exist
- all connections reference real rabbit holes
