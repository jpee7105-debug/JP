App Name: Red Thread

Build Type
Mobile-first app (iOS/Android) + Web admin backend (CMS) for content/research team.

User Roles

Anonymous User (default)

Moderator (can remove/flag content)

Research Editor (can create/edit rabbit holes + sources)

Admin (full permissions, monetization, users, settings)

Backend (Admin + Research CMS)

Goal
A separate web backend where your research team can easily add rabbit holes, nodes, sources, media, and connections without touching code.

Backend Pages to Build

A) Admin Login + Role Management

Create roles: Moderator, Research Editor, Admin

Permissions per role

Audit logs of edits

B) Rabbit Hole Manager

Create/edit rabbit hole
Fields:

Title

Slug

Category tags

Summary

Labels (Verified/Disputed/Speculative/Archived)

Featured toggle

Cover image

Intro video (optional)

Related rabbit holes

Publish status: Draft / Review / Published

Version history

C) Depth Node Editor (the guided “step-by-step” content)

Each rabbit hole has many nodes
Each node includes:

Node title

Node summary/body

Media attachments

Source references (select from source library)

Claim tags

Next node links

Branch links

D) Claim Manager

Create claims linked to a rabbit hole
Each claim includes:

Claim statement (one sentence)

Label (Verified/Disputed/Speculative/Archived)

Evidence list (sources)

Counterpoints list (sources)

Confidence score (0–100)

E) Source Library

Add/manage sources
Fields:

Title

Author / org

Origin country

Publisher

Date

URL or uploaded file

Summary

Stance tag (supporting/critical/neutral)

Credibility score (0–100)

Notes for editors

Where used (auto-generated)

F) Media Library

Upload images/videos/PDFs
Fields:

Type

Caption

Source/origin

Date

Rights/license note

Linked rabbit hole(s)

Linked node(s)

Linked claim(s)

G) Red Thread Link Moderation

Review user-created red line links

Approve / reject / edit label

Auto-detection queue from AI moderation

H) Comment Moderation Dashboard

Filters by most reported, newest, most downvoted

Fields:

Data Model (Simple so the builder AI understands)

Entities:

RabbitHole

DepthNode

Claim

Source

Media

Comment

RedThreadLink

User (anonymous)

Role/Permissions

SponsorSlot

Relationships:

RabbitHole has many DepthNodes, Claims, Media, Sources (via references)

Claim references many Sources and Media

DepthNode references many Sources and Media

Comments belong to RabbitHole and can include RedThreadLinks

RedThreadLinks connect CommentText → RabbitHole (target) and optionally a Node/Claim anchor
